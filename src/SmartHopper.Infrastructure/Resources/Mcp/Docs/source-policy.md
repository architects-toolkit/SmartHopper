# Knowledge Source Policy

Use sources in this order:

1. Current Grasshopper/Rhino runtime evidence from the user's canvas and environment.
2. Live installed-component metadata returned by SmartHopper discovery tools.
3. Official Rhino and Grasshopper documentation at `developer.rhino3d.com`, `docs.mcneel.com`, and `rhino3d.com`.
4. McNeel Discourse for practical, historical, or version-specific discussion.
5. Maintainer documentation for third-party plug-ins.
6. Other catalogues, tutorials, and community sources as secondary evidence.

Do not use an online component catalogue as proof that a component is installed. Check publication date, Rhino version, platform, plug-in version, and whether advice describes a guarantee or a personal convention. Cite sources when research materially affects the answer and state uncertainty when evidence conflicts.
