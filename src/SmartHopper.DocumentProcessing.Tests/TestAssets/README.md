# Test assets

These are **intentional source test inputs** (checked-in fixtures, not generated build
output). They are synthetic transport/extraction fixtures authored for SmartHopper's
multimodal document pipeline — they carry no real research content and are not a
scientific-accuracy fixture.

## Files

- `synthetic-scientific-evidence.pdf` — 4-page synthetic PDF generated by a
  repository-authored fixture script (not vendored):
  - page 1: vector plot (native text, 29 vector paths, zero embedded rasters),
  - page 2: scan-only page (zero native text, one embedded raster),
  - page 3: rotated/cropped page, visible 515x740pt, green annotation,
  - page 4: table/equation page (`12.5 mM`, `9.0 mM`, `E = mc^2`).
- `groundtruth.json` — frozen expected facts extracted by the generation script. Use it
  for assertions; do not re-derive or re-generate.

## Provenance

Generated inside this repository by a repository-authored script for SmartHopper's own
test suite; no third-party content. License: same as the repository (LGPL-3.0-or-later).

No real-world PDFs are vendored: real-file validation runs through local harnesses or
the explicit `SH_TEST_REAL_PDF` environment opt-in, never a silently-skipping unit test.
